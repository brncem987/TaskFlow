Paste codes from the manual

Select lines in the PDF (e.g. CRG §9) and paste here. Each line like L1222: Los datos C1 parte 2… han sido dados de baja. becomes one entry. The code is auto-detected (R####, L####, RM###, CM99#, C99##, A####, TYPE##, RT##); the rest becomes the description. Severity is guessed (rechazado→reject, baja/pendiente→pending, sin errores→accept) and editable afterwards.

How "Update" works

Folders are scanned recursively. A file is identified by path + size + modified time; only unseen files are read and parsed. Re-press Update any time — already-processed files are skipped, so it is safe to run daily. Folder permissions may need re-granting after a browser restart (the buttons remember the last folders and just re-ask).
